# Stage 4 · 逐字稿 → 技能包（能力卡蒸馏）

把多集课程/长视频的逐字稿，蒸馏成**结构化技能包**（能力卡 + 术语表 + 速查 + 索引），便于反复查询与实操。风格对标「仓颉 RIA-TV++」：single 入口 + 能力卡 + 忠实锚点。

> 何时用：多集课程（3 集以上）/ 体系化知识（不是单个知识点）/ 希望以后反复查询与照着做。
> 单集视频直接走 Stage3 HTML 即可，不必上技能包。

## 产物结构
```
<技能名>/
├── SKILL.md                     # single 入口：能力路由表
├── references/
│   ├── overview.md               # 阶段0：课程理解/结构/边界
│   ├── capabilities/*.md         # 能力卡（R-I-A-E-B 模板）
│   ├── glossary.md               # 术语表
│   ├── cheatsheet.md             # 速查
│   └── capability-index.md       # 意图索引
└── resources/                    # 可选计算脚本
```

## 流程（五步）

### 1. 阶段0 · 课程理解
读 overview 素材，产出 `references/overview.md`：
- 一句话主旨、课程骨架（几课、每课解决什么、关系）
- 术语速览表（是什么 / 不能混同）
- 批判与边界（时代局限、立场限制、未证明假设、文本限制）
- 任务清单 T01…（带时间锚点 + 优先级）

### 2. 拆能力（3–8 张，别贪多）
按「用户会问什么 / 想做什么」拆能力，**不是**一课一张。每张能力卡覆盖一个独立任务，用 R-I-A-E-B 模板：

```markdown
# 能力名

## R — 原文与来源
来源：videoXX mm:ss–mm:ss；> 原课关键原话。

## I — 方法解释
是什么 / 为什么重要 / 怎么用（用大白话）。

## A1 — 课程示例与操作步骤
步骤（每步挂时间戳）+ 常见卡点。
## A2 — 合成演练
自造数字/场景走一遍（标明"非原课经历"）。

## E — 输入、输出与完成标准
输入字段 → 输出字段 → 怎么算"做完"。

## B — 边界与判停
何时拒绝/停：缺数据、数值冲突、未核验现行规则。
```

### 3. 术语表
每个术语写：**是什么 / 不是什么（易混）/ 作用 / 来源时间戳**。多课共享同一术语时，注明各课用法差异。

### 4. 速查 + 索引
- `cheatsheet.md`：一句话结论 + 关键数值/红线（数值标「课内示例，非通用」）。
- `capability-index.md`：意图/关键词 → 能力卡映射，路由表没覆盖的兜这里。

### 5. SKILL.md（single 入口）
frontmatter + 核心原则 + **能力路由表**（意图 → 读哪张卡）+ 加载规则（先读入口，再按意图加载 1 张，跨域最多 2 张）+ 边界判停。

## 忠实度铁律（Stage4 同 Stage2/3）
- 每个能力卡/术语/结论**挂原视频时间锚点**，能回看核对。
- 课内示例数值标明「课内示例，非通用红线」。
- ASR 数值冲突时**如实标注冲突**，不强行编一个确定值。
- **合成演练**必须标明"非原课经历/非原作者效果证据"。

## 反例
- ❌ 能力卡写成"该视频主要讲述了…"式套话，零 actionable。
- ❌ 编造视频里没有的数据/结论。
- ❌ 一课一卡且卡内全是摘要，无法照着做。
