# 视频蒸馏的内容分析与验收流程

提取器负责原稿，Agent 负责分析；HTML 渲染器不负责产生知识。所有机器稿均标记未人工核对。

1. 先读取本次 summary.json 的 sources 和 artifacts_dir，核对范围、失败阶段及提取方式。原稿只读，校对另存。字幕稿与 ASR 稿分别保留，不合并成未经说明的原文。
2. 每条视频生成 `03_内容分析.md`：主题与问题、概念定义、论证链、案例输入及计算、实际操作、适用条件、例外、缺失与待核验项。每条关键判断附 source_id、start/end；区分讲师观点与整理者推断。
3. 长视频按主题和时间分块读取，记录已读区间、遗漏区间与跨块关联。禁止只读开头便概括整个视频。
4. 完成逐条分析后生成跨视频综合：共同结论、互补步骤、冲突及条件差异、尚不能回答的问题。共现图只用于定位候选出处。
5. 生成内容 JSON 供 guide_builder 渲染。格式来自 `python scripts/guide_builder.py --print-schema`。另保存证据表：claim_id、结论、source_id、start/end、原文引用、条件、核对状态。结构关系另写前提/因果/步骤/例外/冲突及对应证据，证据不足不连边。
6. 挑三个真实学习问题验收：回答能否回到来源、是否遗漏关键条件、是否把示例数字误当通用阈值。抽查开头/中间/结尾、术语、数值和操作画面。
7. 只有内容核对后才考虑技能包；验证目录和链接通过不等于知识可靠。指南通过 JSON 格式校验也不代表已核对每个时间点。记录完成、部分完成和未完成范围。

未配置百炼云端模式时不调用云端模型；明确配置 provider=bailian 后发送原稿片段/可选OCR文本。不会自动发布或把付费课程材料收入公开仓库。视觉信息提取（硬字幕 OCR、关键帧）仍需另行处理。
