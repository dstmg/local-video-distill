# 小白学习指南 · 内容结构规范（teaching-note-spec）

把「逐字稿」改写成「完全零基础的人也能照着学会」的单页学习指南。**不是总结**，是能学、能练、能自测。生成 Stage 3 产物时严格遵循本节。

---

## 设计原则

- **假设读者对该领域零基础**：不跳步、不堆术语、不默认常识。
- **能照着做**：给出可勾选的步骤清单，每步写明「做到什么算对」。
- **能验证学会没**：自测题带答案与解析（费曼式——让你用自己的话讲）。
- **不编造**：原视频没说的标「以原视频为准」；不替用户下经营/投放结论。
- **忠于原视频叫法**：术语用视频里的说法，并在术语表解释。
- **每节挂时间戳（硬规则）**：每个核心小节都要能回溯到 MT 的时间锚点（`mm:ss`；多课标 `video0X mm:ss`）。课内示例数值标明「课内示例，非通用红线」。ASR 数值冲突时如实标注冲突，不编一个确定值。

---

## 必含章节（顺序固定）

0. **（长视频前置）分块**：>30 分钟 / >1500 行先走 `long-video-chunking.md` 分块读法，否则易丢细节或编造。

1. **总览**
   - 这段视频/这门课在解决什么问题？
   - 面向谁？学完你能干啥（用大白话，不超过 3 句）？
   - 一句话主旨。

2. **前置知识**
   - 需要你先懂啥？没有标「可跳过」。
   - 列 0–3 条，别凑数。

3. **核心概念**
   - 每个概念用三段式：**是什么 / 为什么重要 / 怎么用**。
   - 数量按视频实质内容，3–8 个为宜。
   - 配「术语表」小节：原视频术语 → 大白话解释。

4. **步骤 / 流程清单**
   - 可勾选的有序步骤（HTML 用 `<input type=checkbox>` 或带 □ 的列表）。
   - 每步：做什么 + 做到什么算对 + 常见卡点。
   - 明确分支（如「走 A 路径 / 走 B 路径」）。

5. **常见误区**
   - 新手最容易踩的 3–5 个坑。
   - 每条：`误区` → `正确做法` → `为什么`。
   - 优先用原视频里明确提醒或反例的内容。

6. **实例演算**
   - 一个具体数字/场景，从头算/做到尾。
   - 展示中间每一步，不跳。让零基础能跟着复现。
   - 例：原价 X、券后 Y、差价 Z 怎么算；或某指标 12.5 / 40% 如何得出。

7. **自测题**
   - 3–5 道，覆盖「概念理解 + 计算/操作」。
   - 每题：**题目** → 折叠/分隔的**答案与解析**。
   - 至少 1 道费曼式：「用自己的话解释 XXX」。

8. **下一步**
   - 学完去练什么（最小行动）。
   - 相关延伸（可标注「进阶，原视频未展开」）。

9. **原文索引**
   - 关键结论对应原视频时间戳（如 `video03 46:04–60:29`），方便回看。
   - 来自 MT 的时间戳。

---

## 输出形式约束

- 单页 HTML，版式复用 `learning-guide-template.html`（白底/冷白 + 中性灰、主色橙 `#ea580c`、移动端响应式、右下角「✏️修改」按钮）。
- 生成时**只替换正文内容区**，保留模板的 `<style>` 与「✏️修改」脚本，保证风格一致。
- 章节用锚点导航（顶部目录，点击跳转），移动端可折叠。
- 自测题答案默认隐藏/可展开，避免一眼看到答案。

---

## 反例（不要这样做）

- ❌ 把逐字稿压缩成一段摘要就交差（这是总结，不是能学的指南）。
- ❌ 堆砌「该视频主要讲述了……」式套话，零 actionable 内容。
- ❌ 编造视频里没有的数据或结论。
- ❌ 满篇术语不下定义，零基础看不懂。
