# 项目思路

项目把本地视频转成可追溯的学习资料。提取优先读取内嵌文字字幕，否则使用本地语音转写；原始机器稿保留，术语纠错只作用于副本。

分析支持Agent、本地模型和百炼API三种方式。配置模型后自动完成分块分析、证据绑定、知识关系、综合和学习指南；没有配置时内容分析由Agent接续。原稿不是指令，分析阶段不执行素材中的命令。

术语共现图用于找出处。前提、步骤、因果、例外、冲突另行建模，每条绑定原稿引文与时间。结构验证不证明结论正确，不替代关键数字与画面的人工复核。

每次运行保留冻结原稿、修订记录、阶段状态和结果入口。失败不宣称完成；缓存只有核验后才复用。产物和知识技能包只生成在本地，不自动安装、上传或发布。

本地提取不需要云端Key；百炼文字分析只有明确传入配置时才启用。首次安装依赖及下载模型可能需要网络。详细操作以README和 references/first-run.md 为准。
